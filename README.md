---

## Setup Instructions  
1. Clone the repository:
   `git clone https://github.com/liar-01/pulse.git`
2. Install dependencies:
   `npm install`
3. Start the development server:
   `npm start`

---

## Features Implemented
**Required Features**
- Post feed with infinite scroll
- Profile page with dynamic routing (/profile/userId)
- Like/comment functionality with real-time updates
- Dark mode toggle (persistent via localStorage)

**Bonus Features**
- Dark/Light Mode Toggle
- Responsive design
- Animations
